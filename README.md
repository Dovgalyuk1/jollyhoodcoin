# JOLLYHOOD ($JOLLYHOOD)

Один экран: персонаж, вордмарк, кнопки. Клик по персонажу — монеты и смешок.
Мини-игра CATCH MY FEATHER — поймать перо 8 раз.

Настройки — первый `<script>` в `index.html`:

```js
window.CONTRACT = "";  // адрес контракта
window.TWITTER  = "";  // ссылка на X
window.BUY_URL  = "";  // ссылка на покупку (пока пусто — кнопка серая)
```
